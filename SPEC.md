# Voice-Type — Спецификация

## Краткое описание
Система голосового ввода текста в любое приложение. Нажал → сказал → текст вставлен.
Работает на Mac и iPhone. Своё решение, без подписок на сторонние сервисы.

## Проблема
Набирать текст руками — долго. Встроенная диктовка Apple работает плохо на русском,
не форматирует текст, не расставляет абзацы. Сторонние приложения (Whisper apps) —
платные подписки, данные уходят на чужие серверы.

## Решение
Свой API-сервер (Deepgram Nova-2) + клиенты на каждой платформе.
Контроль данных, без подписок, оплата только за Deepgram (~$0.0043/мин).

## Пользователь
Дмитрий Ледовских — эксперт по нейросетям. Использует для:
- Быстрые сообщения в мессенджерах (Telegram, WhatsApp)
- Длинные промпты для AI (1-5 минут)
- Тексты, заметки, письма

## Сценарии использования
- Короткие сообщения (5-30 сек) — 70% случаев
- Средние тексты (30 сек - 2 мин) — 20% случаев
- Длинные диктовки (2-5 мин) — 10% случаев

## Язык
- Основной: русский (95%)
- Вставки: английские термины (deepgram, deploy, API, Claude)
- Настройка Deepgram: language=ru, smart_format=true, punctuate=true

### Компоненты

#### 1. API-сервер (VPS)
- Фреймворк: FastAPI + uvicorn
- Эндпоинт: POST /transcribe (принимает аудио, возвращает текст)
- Эндпоинт: GET /health (проверка)
- Транскрибация: Deepgram Nova-2
- Авторизация: Bearer token (VOICETYPE_TOKEN)
- Порт: 8100 (внутренний), nginx reverse proxy с HTTPS
- Размещение: Beget VPS (рядом с transcriber-bot)

#### 2. Mac-клиент (Python)
- Фоновый скрипт, работает в терминале
- Горячая клавиша: Ctrl+Shift+Space (настраивается)
- Зажал → запись с микрофона (16kHz, mono, WAV)
- Отпустил → отправка на API → текст в буфер → автовставка (Cmd+V)
- Звуковой фидбек: звук начала/конца записи
- Зависимости: pyaudio, requests, pyperclip, pynput

#### 3. iOS Shortcut
- Триггер: виджет на Home Screen или Back Tap (двойной тап)
- Действия: Record Audio → Upload to API → Copy to Clipboard → Show Notification
- Формат: стандартный iOS (m4a)
- После получения текста: пользователь вставляет из буфера

## Технические детали

### Deepgram параметры
- model: nova-2
- language: ru
- smart_format: true
- punctuate: true
- paragraphs: true

### Аудио формат
- Mac: WAV, 16kHz, 16-bit, mono (оптимально для Deepgram)
- iOS: m4a/aac (стандартный iOS формат, Deepgram принимает)
- Лимит: 25MB (~25 минут записи)

### Безопасность
- API защищён Bearer токеном
- HTTPS через nginx (Let's Encrypt)
- Токен хранится в .env на сервере и в переменных окружения клиентов
- Аудио не сохраняется на сервере (обрабатывается в памяти)

### Мониторинг
- GET /health — проверка доступности
- Логирование запросов (время, размер файла, длительность транскрибации)

## Известные ограничения

1. **iOS Shortcut** — не идеальный UX (нужен лишний тап для вставки из буфера)
2. **Mac permissions** — macOS требует разрешения для микрофона и Accessibility
3. **Оффлайн** — не работает без интернета (Deepgram — облачный)
4. **Английские слова** — при language=ru могут транскрибироваться кириллицей ("дипграм" вместо "Deepgram")

## Стоимость
- Deepgram Nova-2: ~$0.0043/мин ($0.26/час)
- VPS: уже оплачен (Beget)
- Итого при 30 мин диктовки в день: ~$4/мес
