# Voice-Type на iPhone

Кнопка на телефоне: нажал → продиктовал → текст с пунктуацией в буфере
обмена. Делается штатным приложением **«Команды»** (Shortcuts) за 5 минут,
ничего устанавливать не нужно.

Понадобятся: адрес твоего сервера (`https://...`) и токен из
`VOICETYPE_TOKEN` (см. server/.env).

## Собираем команду

Открой «Команды» → «+» (новая команда) → добавляй действия по очереди
(ищи их по названию в поиске действий):

1. **Записать аудио** (Record Audio)
   - Качество: Нормальное
   - Завершение записи: По касанию

2. **Получить содержимое URL** (Get Contents of URL)
   - URL: `https://ТВОЙ-ДОМЕН/transcribe`
   - Разверни стрелочкой «Показать больше»:
     - Метод: **POST**
     - Заголовки → Добавить: Ключ `Authorization`, Текст `Bearer ТВОЙ_ТОКЕН`
       (слово Bearer, пробел, токен — одной строкой)
     - Тело запроса: **Файл** → выбери переменную «Аудиозапись» из шага 1

3. **Получить значение словаря** (Get Dictionary Value)
   - Получить значение для ключа: `text`

4. **Скопировать в буфер обмена** (Copy to Clipboard)

5. **Показать уведомление** (Show Notification) — опционально
   - В текст уведомления вставь переменную «Значение словаря» —
     будешь видеть распознанный текст сразу

Назови команду (например, «Голос») и сохрани.

## Куда повесить кнопку

- **Action Button** (iPhone 15 Pro и новее): Настройки → Кнопка действия →
  Быстрая команда → «Голос». Зажал кнопку → говоришь → текст в буфере.
- **Двойной тап по крышке**: Настройки → Универсальный доступ → Касание →
  Касание задней панели → Двойное касание → «Голос».
- Или просто иконка на рабочий стол: в настройках команды →
  «Добавить на экран „Домой"».

## Если не работает

- **Уведомление приходит пустым** → почти всегда неверный токен или он
  удалён вместе с заголовком. Проверь заголовок `Authorization`: значение
  начинается со слова `Bearer` + пробел + токен.
- **«Не удалось связаться с сервером»** → проверь URL: `https://`, домен,
  `/transcribe` на конце.
- Текст без знаков препинания → на сервере не настроен OPENROUTER_API_KEY
  (см. server/.env.example) — вернулся сырой текст распознавания.
