## О проекте

Свой Wispr Flow без подписок: голос и текст ходят только через сервер
владельца. Подробное описание и установка — в `README.md`.

**Стек:** Python 3.10+ (сервер: FastAPI + uvicorn + httpx; Mac-клиент:
pynput + pyaudio + PyObjC), Deepgram nova-3 (распознавание), OpenRouter
gemini-2.5-flash-lite (пунктуация), nginx + systemd на VPS.

**Модули:**
- **server/** — API: POST /transcribe (аудио → Deepgram → LLM-пунктуация →
  текст), GET /health. Один файл `main.py`.
- **clients/mac/** — клиент: `voice_type.py` (правый Cmd, запись,
  сеть), `overlay.py` (пилюля с волной, AppKit в главном потоке),
  `install.sh` (сборка VoiceType.app + launchd).
- **clients/ios/** — инструкция сборки шортката (кода нет).

**Структура:**
```
server/          main.py, requirements.txt, .env.example
clients/mac/     voice_type.py, overlay.py, install.sh,
                 com.voicetype.agent.plist (шаблон), .env.example
clients/ios/     README.md
docs/            датированные спецификации (архив, не актуализировать)
SPEC.md          первоначальная спецификация (исторический документ)
```

## Правила

- **Простой язык.** Объясняй как другу. Сложную команду — человеческими
  словами, зачем она.
- **Не выдумывай факты.** Про проект — только из кода и `MEMORY.md`.
  Нет данных — спроси, не сочиняй.
- **Не выдумывай env-переменные, флаги, поля, ключи**, которых нет в
  исходниках.
- **Репозиторий ПУБЛИЧНЫЙ.** Ни токенов, ни IP, ни личных данных — ни в
  коде, ни в доках, ни в коммитах. Секреты только в `.env` (в .gitignore).
  Перед push при малейшем сомнении — `gitleaks git .`.
- **VoiceType.app-бандл не пересобирать без нужды** — новая подпись =
  слетают TCC-разрешения macOS (детали в `knowledge/`).
- **AppKit только в главном потоке**; из других потоков — через
  `AppHelper.callAfter` (см. `overlay.py`).

## 🔴 Документация — держать в синхроне с реальностью

**После каждого изменения кода или структуры обновляй соответствующую
документацию. Документация всегда должна соответствовать тому, что реально
есть в проекте.** Это обязательный шаг, а не пожелание.

| Что изменил | Что обновить |
|---|---|
| Новый модуль/файл/инструмент | `CLAUDE.md` (структура), `README.md` |
| Добавил/убрал env-переменную | `server/.env.example` или `clients/mac/.env.example` + таблица в `README.md` |
| Поменял поведение клиента или API | `README.md`; касается шортката — `clients/ios/README.md` |
| Сменил модель распознавания/пунктуации | `README.md`, `.env.example` |
| Изменил установку (install.sh, plist, разрешения) | `README.md` (Часть 2), `clients/ios/README.md` |

`SPEC.md` и `docs/` — исторические снимки, их НЕ актуализируем.

Проверка перед завершением задачи: «Я изменил структуру или поведение —
не разошлась ли документация с реальностью?». Разошлась — права реальность,
документ правим.

Правила правок: факты (путь, строка в таблице, версия) — правь молча через
`Edit`. Новые секции, удаления, рерайт больше 10 строк — сначала спроси.
